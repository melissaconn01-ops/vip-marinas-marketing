## Tracking Notes

Tracking is a corporate-wide project. Marina-specific tracking issues can exist, but they should roll up to the corporate tracking project (CORP-TRK-001) when they affect portfolio reporting or system standards.

## CRM / Lead Management Notes

CRM, lifecycle stages, lead source definitions, contact method definitions, and lead-to-booking reporting should be standardized across the portfolio. Website is not a lead source — it is a contact path or conversion location.

---

## Reporting Notes

GitHub is currently the structured source of truth. Airtable may become the visual dashboard layer once the GitHub structure is stable.

---

## Brand / Messaging Notes

Brand and messaging standards should balance portfolio consistency with marina-level differentiation. For Meridian Marina and Bahamas Run creative, use the Meridian-style color scheme as the default visual direction: blues/navy with aqua, turquoise, seafoam accents, and clean nautical white space.

When creating Meridian items, ask whether the piece is for print or digital. Print can rely more heavily on the color palette and cleaner graphics. Digital may need more photography, but should still incorporate the Meridian colors where possible.
